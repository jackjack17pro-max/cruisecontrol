# Cruise Control

**Cruise Control** — это лёгкая и мощная утилита для ОС Windows, предназначенная для создания макросов, автоматизации нажатий и удержания клавиш. Программа идеально подходит для геймеров и разработчиков, которым требуется автоматизировать рутинные действия или построить сложные цепочки ввода с миллисекундной точностью.

---

## 🌟 Главные преимущества

* **Бесшовный переход (Seamless State):** Перехват низкоуровневых событий клавиатуры предотвращает сброс спринта или бега в играх при активации макроса.
* **Гибкая цепочка действий:** Возможность добавлять неограниченное количество прожимаемых клавиш для каждого профиля.
* **Миллисекундная точность:** Настройка индивидуальной задержки перед нажатием (`Delay`) и времени удержания (`Hold`) для каждой клавиши.
* **Два режима активации:**
  * **Зажатие:** Макрос работает, пока вы удерживаете кнопку-триггер.
  * **Нажатие:** Одиночный клик запускает всю цепочку до конца.
* **Поддержка мыши и боковых кнопок:** В качестве триггеров и прожимаемых клавиш можно использовать `LBM`, `RBM`, `MBM`, а также боковые кнопки мыши `XButton1` и `XButton2`.
* **Автоматическое сохранение:** Все настройки профилей мгновенно сохраняются в файл `config.ini`.
* **Автообновления:** Встроенный модуль проверки и скачивания свежих релизов напрямую с GitHub.

## 📖 Подробное руководство по использованию

### 1. Добавление и управление профилями
* **Создание профиля:** Нажмите кнопку **«Добавить профиль»** в верху окна.
* **Удаление профиля:** Нажмите кнопку **«X»** в правой части строки нужного профиля.
* **Сброс настроек:** Кнопка **«Сбросить всё»** возвращает конфигурацию к базовому состоянию.

---

### 2. Настройка триггера (Активатора)
1. Нажмите на первую кнопку в строке профиля (по умолчанию **`[Выбрать]`**).
2. Нажмите любую клавишу на клавиатуре или боковую кнопку мыши.
3. Нажмите на соседнюю кнопку режима, чтобы выбрать поведение:
   * **`Зажатие`** — цепочка выполняется последовательно и удерживается до тех пор, пока физически зажата кнопка-триггер.
   * **`Нажатие`** — одиночный клик по триггеру полностью проигрывает всю цепочку макроса.

---

### 3. Настройка цепочки клавиш
Каждый профиль содержит список прожимаемых клавиш. Для каждой клавиши задаются 3 параметра:

| Элемент | Название | Описание |
| :--- | :--- | :--- |
| **Кнопка** | `Клавиша` | Нажмите её и задайте целевую кнопку (буква, цифра, Shift, Ctrl, мышь и т.д.). |
| **Поле 1** | `Задержка (мс)` | Пауза в миллисекундах **перед** нажатием этой клавиши. |
| **Поле 2** | `Удержание (мс)` | Время удержания клавиши нажатой.<br>• `0` = удерживать всё время, пока зажат триггер.<br>• `> 0` (например, `500`) = зажать ровно на 500 мс и отпустить. |

* **Добавление клавиши:** Нажмите **`+`** в строке профиля, чтобы удлинить цепочку макроса.
* **Удаление клавиши:** Нажмите **`-`** возле конкретной клавиши, чтобы убрать её из цепочки.

---

### Пример настройки для спринта (Shift + W):
1. **Триггер:** `XButton2` (Режим: *Зажатие*).
2. **Первая клавиша:** `ShiftKey` | Задержка: `0` | Удержание: `0`.
3. **Вторая клавиша:** `W` | Задержка: `0` | Удержание: `0`.

## ⚠️ Заметка о ложных срабатываниях антивирусов

При скачивании программы или её работе некоторые антивирусы (включая Windows Defender) могут выдавать предупреждения (*False Positive*).

### Почему это происходит:
1. **Низкоуровневые хуки (WinAPI):** Программа использует функции `SetWindowsHookEx`, `keybd_event` и `mouse_event` для глобального перехвата и эмуляции ввода. Подобные механизмы используются эвристическими анализаторами для поиска клавиатурных шпионов (Keylogger).
2. **Отсутствие цифровой подписи:** Программа является бесплатным Open-Source проектом и не имеет дорогостоящего сертификата разработчика (Code Signing Certificate).

> 💡 **Безопасность гарантирована:** Весь исходный код программы полностью открыт и доступен в данном репозитории. Вы можете лично проверить его или собрать исполняемый `.exe` файл самостоятельно из исходников в Visual Studio!
